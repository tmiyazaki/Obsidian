# アンチパターン目録

「**よくある失敗**」を**横断的に**集約。実プロダクトで遭遇したら即対処。各ノートにも個別にあるが、ここでは**症状 → 領域 → 対処** で逆引きできる。

## 🚨 高頻度・高インパクト

### 「動いている」は正しい指標ではない

| 症状 | 原因 | 対処 |
|---|---|---|
| 雑な UI でも動く | UX 軽視 | [[../30-Interface/UX-Principles]] |
| エラー処理なし | 例外握り潰し | [[../10-Coding/Error-Handling]] |
| アクセシビリティ未対応 | チェック忘れ | [[../30-Interface/Accessibility]] |
| パフォーマンス未計測 | 体感のみで判断 | [[../10-Coding/Performance]] |
| セキュリティ後付け | 設計時に無視 | [[../10-Coding/Security]] |

## 🧠 コードの腐敗

### 命名

→ [[../10-Coding/Naming]] / [[../40-Bridge/Naming-as-Design]]

- `data`, `info`, `manager`, `helper` のような**抽象すぎる名前**
- `getUser2()` (旧版を残してリファクタを諦めた跡)
- 単位なし: `timeout`(秒?ミリ秒?)
- 同概念に**複数名前**: `user_id` / `userId` / `uid` 混在

### 関数・クラス

→ [[../10-Coding/Clean-Code]]

- 1 関数が画面に**収まらない**
- 引数 4+ (ドメインオブジェクト候補)
- フラグ引数 (`doSomething(true, false, true)`)
- God Object (何でもやるクラス)

### 設計

→ [[../10-Coding/SOLID-Principles]] / [[../10-Coding/Architecture-Layers]]

- ビジネスロジックから**フレームワークを import**
- 1 機能変更で**多ファイル**が壊れる(散弾銃手術)
- `switch (type)` が**複数箇所**で同形(多態化候補)
- DB の Row 型を**直接ドメイン型**として使う

### テスト

→ [[../10-Coding/Testing-Strategy]]

- カバレッジ 100% だが**振る舞いを保証しない**
- モック地獄 (テスト本体より長いセットアップ)
- 実装をテスト (`_privateHelper を呼んだか`)
- Flaky テスト**放置**
- E2E のみで Unit なし (アイスクリームコーン)

## 🎨 デザインの腐敗

### 階層

→ [[../20-Design/Visual-Hierarchy]]

- 太字だらけ(全部強調 = 強調なし)
- 5 色以上のアクセントが**競合**
- サイズだけの階層(色・余白なし)

### タイポグラフィ

→ [[../20-Design/Typography]]

- フォント 4 種以上同一画面
- 本文 14px 未満(モバイル)
- 行長 100 字超
- 中央揃えの長文
- 日本語フォント未指定で**中華フォント**になる

### 色

→ [[../20-Design/Color-Theory]] / [[../20-Design/Dark-Mode]]

- ブランドカラーがアクション・エラー両方に
- 色だけで意味
- ダークモードでピュアブラック背景
- コントラスト不足 (WCAG 違反)

### マテリアル

→ [[../20-Design/Material-Surfaces]]

- ニューモーフィズムでボタンと飾りが**区別不能**
- グラスモーフィズム全画面で**何が手前か不明**
- 過剰アニメ背景でバッテリー枯渇

## 🖱 インターフェースの腐敗

### フォーム

→ [[../30-Interface/Forms-and-Input]]

- 必須項目の表示が**色だけ**
- パスワード制約を**送信失敗で初めて知る**
- バリデーション失敗で**入力値が消える**
- プレースホルダのみ(ラベルなし)
- `autocomplete` 未指定

### ナビゲーション

→ [[../30-Interface/Information-Architecture]]

- ハンバーガーに**主要機能を全部**隠す
- 階層が**3 段以上**深い
- 似た名前のメニューが複数 (`設定` と `環境設定`)
- 主要 CTA が**5 クリック先**

### モーダル

→ [[../30-Interface/Interaction-Patterns]]

- Esc で閉じない
- フォーカストラップなし
- 重ねるモーダル
- 長文を**モーダル内**で読ませる

### ローディング

→ [[../30-Interface/Loading-States]]

- スピナーが**100ms 未満**でチラつく
- 「Loading...」だけが何秒も
- 進捗を**偽装**(突然 99% で停止)
- エラー時に**ホワイトアウト**
- Empty State が「No data」だけ

### モバイル

→ [[../30-Interface/Mobile-Patterns]]

- ホバー前提
- 画面端ぎりぎりに重要要素 (セーフエリア無視)
- 起動直後に**通知 + 位置情報 + カメラ**連発
- ハンバーガーで**ボトムナビ放棄**

### AI UI

→ [[../30-Interface/AI-LLM-Interfaces]] / [[../30-Interface/Agentic-AI-Patterns]]

- 空白の入力欄だけ(何ができるか不明)
- 出典なしの**確信ありげな**生成
- 中断ボタンなし
- 自動実行で**不可逆操作**(承認なし)
- 学習に使うか不透明

## 🔐 セキュリティ・プライバシー

→ [[../10-Coding/Security]] / [[../40-Bridge/Privacy-by-Design]]

- フロントエンドだけの認可
- パスワードを**MD5 / SHA1**で保存
- API キーをコードに直書き
- ログに **PII**(メール・トークン)を出力
- HTTP リダイレクトを許す
- データ収集が**理由不明**で過剰
- 削除リクエスト**手作業**処理
- 第三者データ共有を**ユーザーに告げない**
- 「**いつか使うかも**」でデータ無限保持

## 🌍 国際化

→ [[../40-Bridge/Internationalization]]

- 文字列をコードに**直書き**
- 文字列の連結で文を組む (語順依存)
- 単複・性別を考慮しない
- 固定幅の UI(テキスト膨張で破綻)
- `margin-left` (RTL で逆転しない)
- アイコンに**焼き込み文字**
- 「Last name」のような英語前提
- `Date.toString()` で表示

## ⚡ パフォーマンス

→ [[../10-Coding/Performance]] / [[../40-Bridge/Performance-as-UX]]

- 全 await を直列化(`Promise.all` 使わず)
- ヒーロー動画 50MB
- 画像に `width / height` なし (CLS 悪化)
- 第三者スクリプト**累積監視なし**
- N+1 クエリ放置
- インデックス**なし** or **全列に**
- キャッシュ**入れただけ**で計測なし

## 🏗 運用と進化

### CI / CD

→ [[../10-Coding/CI-CD]]

- 「金曜デプロイ禁止」(安全網が脆弱)
- ロールバック手順が**口伝**
- Feature Flag が**数百個**残ったまま
- secret を CI ログに出力
- CI 30 分超(待ちが集中切れ)

### 観測性

→ [[../10-Coding/Observability]]

- ログがフリーテキストで grep のみ
- リクエスト ID が**伝播せず**サービス間で追えない
- アラート過剰で**全部 mute**
- 本番で**初めて挙動**が分かる(canary なし)
- ログに **PII** 出力

### マイグレーション

→ [[../40-Bridge/Migrations-as-Product]]

- Big Bang Migration (一晩で全部切替)
- 後方互換性なし変更
- 並行稼働期間が**短すぎる**
- ロールバック計画**なし**
- バックフィルが**夜間バッチ 1 回**で失敗放置

### 技術的負債

→ [[../40-Bridge/Tech-Debt]]

- 「**汚いコード**」と狭く理解
- 全部 P1、誰も着手せず
- 全書き直し (Big Rewrite)
- 個々が**勝手に**直して PR が膨れる
- 事業と技術が**会話しない**
- 「次のスプリントで」が永遠に来ない

### SRE

→ [[../40-Bridge/Site-Reliability-Engineering]]

- 100% 稼働を目指す(コスト爆発)
- ポストモーテムを**犯人探し**
- アラート疲労で全 mute
- オンコールが**燃え尽き**製造
- ステータスページ**なし**
- Chaos を**本番でいきなり**

## 🤝 チームと文化

→ [[../40-Bridge/Critique-Culture]]

- 公開 Slack で**個人を非難**
- 沈黙のまま PR をマージ ("LGTM" だけ)
- 上司の意見が**自動で勝つ**
- 「**意見を求める**」と言いつつ既に決定済み
- ブレストで**声が大きい人**に支配
- 形式的な Sandwich フィードバック
- 失敗を**個人責任**にする犯人探し

## 🚀 プロダクト戦略

→ [[../40-Bridge/Discovery-and-Validation]] / [[../40-Bridge/Roadmapping-Prioritization]]

- 「**ユーザーが言ったから**」直接実装
- 機能リスト型ロードマップ(成果なし)
- A/B テストの**結果を見て**短期 KPI で採用 → 長期 LTV 悪化
- 検証なしで**6 ヶ月の機能**着手
- ステークホルダーの**声の大きさ**で優先度
- 仮説に**反証可能な基準**がない

## 💰 価格・課金

→ [[../30-Interface/Pricing-Monetization-UX]]

- 隠れた料金(最終で発覚)
- 自動更新を**目立たない**
- 解約が**3 階層下** or **電話必須**
- 「Free」だが実際は**カード必須**
- 使用量上限**なし** → 課金事故
- B2B プランの「Contact Sales」しかない

## 🎯 倫理

→ [[../40-Bridge/Ethical-Design]]

- Confirmshaming(拒否で罪悪感)
- カウントダウンが**虚偽** or リロードでリセット
- メルマガ購読**強制チェック**
- 「最後のチャンス」が**毎日**届く
- 子どもアカウントに広告ターゲティング
- アルゴリズムの**不透明性**

## 🤖 AI 固有

→ [[../40-Bridge/AI-Evaluation-Safety]] / [[../40-Bridge/AI-Augmented-Development]]

- Eval なしでリリース
- バージョンアップで**性能逆行**を見逃す
- Hallucination 対策**なし**で重要情報生成
- Prompt Injection 対策**なし**
- 個人情報を**LLM に送る**
- コスト上限**なし**で無限ループ
- AI 開示**なし** (ユーザーが人間と思う)
- AI 生成を**理解せず**マージ

## 📁 ファイル・データ

→ [[../30-Interface/File-Management-UX]] / [[../10-Coding/Database-Design]]

- アップロード進捗なし
- 失敗時にリトライ手段なし
- ゴミ箱なし、即消滅
- お金を `float` で保存
- タイムゾーン不明な `timestamp`
- ソフトデリート**書き忘れた** WHERE
- 外部キーなし

## 🌐 マルチテナント

→ [[../10-Coding/Multi-tenancy]]

- すべてのクエリに**手動で**`tenant_id`(忘れる)
- 1 顧客の要望でコード**直書き分岐**
- テナント管理者が**他テナント**を見える
- 監査ログに `tenant_id` がない

## 🎢 ローカルファースト

→ [[../40-Bridge/Local-First-Sync]]

- 競合解消ロジック**なし** → データ消失
- 暗号化なしで**機密データ**ローカル保存
- 同期失敗を**ユーザーに伝えない**
- 容量超過で**何も書けなくなる**

## ⚖️ コンプライアンス

→ [[../40-Bridge/Compliance-and-Regulations]]

- コンプラを**事業終盤に**着手
- ポリシーだけ作って**実装が伴わない**
- 漏洩通知を**遅延**
- ユーザー権利を**問合せフォーム**経由のみ
- DPA 未締結のベンダ利用
