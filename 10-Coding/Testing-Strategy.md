# テスト戦略

## 一行で

> テストは「**設計のフィードバック**」であり、「変更を恐れない自由」のためのインフラ。

## なぜ重要か

テストの目的はバグを見つけることだけではありません。**自信を持って変更できる範囲を広げる**ことが本質です。テストがないコードは、機能追加のたびに作者の頭の中だけで回帰確認することを強要します ― これは速度を下げる最大の要因。

## テストピラミッド

```
       /\
      /E2E\        少数 — 遅い・脆い・本物に近い
     /------\
    /Integ.  \    中程度 — モジュール間結合
   /----------\
  /  Unit      \  多数 — 速い・狭い範囲
 /--------------\
```

- **Unit**: 1 関数/1 クラスを孤立させて検証。msec オーダー。
- **Integration**: 複数モジュール、DB や HTTP クライアントを含む。
- **E2E**: ブラウザで本物のフロー。リリース前のスモーク。

E2E に頼りすぎる「アイスクリームコーン」は遅い・落ちやすい・原因特定が困難というアンチパターン。

## テストの 4 つの目的を区別する

| 種類 | 何のため | 速度 | 量 |
|---|---|---|---|
| 回帰テスト | 既存挙動の固定 | 速い | 多 |
| 仕様テスト (BDD) | 仕様の例示 | 中 | 中 |
| 受け入れテスト | ユーザーストーリーの検証 | 遅い | 少 |
| プロパティテスト | 不変条件の探索 | 速〜中 | 中 |

## TDD: Red → Green → Refactor

1. **Red**: 失敗するテストを書く(まだ実装はない)
2. **Green**: テストが通る**最小限**のコードを書く(美しさは無視)
3. **Refactor**: テストを緑に保ったまま構造を整える

TDD の真価はバグ防止より「**設計の引力**」。テストしにくい構造はそもそも結合度が高すぎることを教えてくれる。

## 良いテストの性質 (FIRST)

- **Fast**: ms オーダー。遅いテストは書かれなくなる
- **Independent**: 順序に依存しない、共有状態を持たない
- **Repeatable**: 何度走らせても結果が同じ(時刻・乱数・外部 API は要差し込み)
- **Self-validating**: 結果が `pass/fail` で自動判定される(目視 NG)
- **Timely**: 実装と同時/直前に書く

## アンチパターン

### モック地獄

```ts
when(repo.find(any)).thenReturn(...);
when(cache.get(any)).thenReturn(...);
when(logger.log(any)).thenReturn(...);
when(metrics.send(any)).thenReturn(...);
// テスト本体より長いセットアップ
```

→ そのクラスは協力者が多すぎる。SRP 違反。

### 実装をテストする

```ts
expect(service._privateHelper).toHaveBeenCalledWith(...);
```

privateな手段をアサートすると、リファクタの自由を失う。**入出力**をテストせよ。

### 一個のテストで全部

「`should work` で 50 アサーション」は失敗時の原因が読めない。**1 テスト 1 振る舞い**。

### Flaky を放置する

「たまに落ちる」テストは信頼を毀損し、最終的に**全テストが無視される**。即直すか即削除。

## テストダブル(用語の整理)

| 名称 | 役割 |
|---|---|
| Dummy | 渡されるが使われない |
| Stub | 決まった値を返す |
| Spy | 呼ばれたか記録する |
| Mock | 期待される呼び出しを定義 |
| Fake | 実装はあるが本物より軽量 (in-memory DB 等) |

迷ったら **Fake > Stub > Mock** の順で検討。Mock は呼び出し順や回数の検証で**実装に強く結合**するため最終手段。

## カバレッジの嘘

カバレッジ 100% は**バグゼロを意味しない**。`if (x) ...` の `else` を通っていなくても、`x === false` の境界条件は別問題。カバレッジは**書き忘れの検出**には使え、**品質の証明**には使えない。
