# 余白とリズム

## 一行で

> 余白は「**何も無い場所**」ではなく「**意味の関係性を運ぶ要素**」。リズムは余白を**規則化**して認知負荷を下げる。

## なぜ重要か

ユーザーは要素を**独立**に見ているのではなく、**関係**として見ています。近いものは仲間、離れているものは別グループ。Gestalt の**近接の法則**は、余白がそのままグルーピングのシグナルになることを示しています。

> "White space is to be regarded as an active element, not a passive background." — Jan Tschichold

## スペーシングスケール

タイプスケール同様、**離散値の階段**を持つ。任意ピクセルを許すと一貫性が崩壊する。

### 4 / 8 px ベースのスケール例

```
0 → 2 → 4 → 8 → 12 → 16 → 24 → 32 → 48 → 64 → 96 → 128
```

- 4px / 8px は最小単位として広く採用される
- 1.5 倍刻み(8 → 12 → 16 → 24)で滑らかな増加
- 設計時はこのスケールに**スナップ**する

### 用途別の目安

| 単位 | 用途 |
|---|---|
| 2–4 | アイコンとラベルの間 |
| 8–12 | フォーム要素の内側パディング |
| 16 | 関連要素間の標準ギャップ |
| 24–32 | セクション内のブロック間 |
| 48–64 | セクション間 |
| 96–128 | 大きな区切り(LP) |

## 関係性を余白で語る

「**外側より内側を狭く**」が原則:

```
[ 見出し ]
  ↕ 8px        ← 関連が強い(タイトルと本文)
[  本文  ]

  ↕ 32px      ← 関連が弱い(別セクション)

[ 次の見出し ]
```

逆になると、本文が**次のセクションのもの**に見えてしまう。

## 縦のリズム (Vertical Rhythm)

行送りに合わせて**ベースラインを一定間隔**にすると、ページ全体が音楽のリズムを持つ:

```
ベースライン = 8px
本文 line-height = 24px (= 8 × 3)
H2 line-height = 32px (= 8 × 4)
要素のマージン = 16, 24, 32px (= 8 × n)
```

CSS では `line-height` と `margin` を**ベースラインの倍数**で揃えるだけで自然なリズムができる。

## ホワイトスペースの 2 種類

| 種類 | 役割 |
|---|---|
| **Macro** ホワイトスペース | レイアウト全体の余白(セクション間など) |
| **Micro** ホワイトスペース | 文字間、行間、ボタン内の余白など |

両者は別のレイヤーで設計する。

## CSS への落とし込み

```css
:root {
  --space-1: 4px;
  --space-2: 8px;
  --space-3: 12px;
  --space-4: 16px;
  --space-6: 24px;
  --space-8: 32px;
  --space-12: 48px;
  --space-16: 64px;
}

.card {
  padding: var(--space-6);
  display: flex;
  flex-direction: column;
  gap: var(--space-4);     /* 内側の関連要素 */
}

.card + .card {
  margin-top: var(--space-8);  /* 外側の区切り */
}
```

`gap` を使うと最初/最後のマージンを気にせずリズムを作れる。

## 「余白を減らせ」は危険な要請

ステークホルダから「もっと情報を詰め込んで」と言われがちだが、詰めると:
- グルーピングが崩れる
- 階層が見えなくなる
- 視線の休憩がなくなる
- ブランドの**プレミアム感**が消える

「**情報量**」と「**情報の理解度**」は別物。情報を減らすか、ページを分けるか、コンポーネントを変える方が先。

## アンチパターン

- スケールに乗らない**任意ピクセル**(13px, 17px…)
- 全要素が等間隔(階層が消える)
- 内側より外側のほうが詰まっている(関連性が逆転)
- スマホで**画面端ぴったり**に貼り付け(タップ・読みづらさ)

## チェックリスト

- [ ] **スペーシングスケール**を持っているか
- [ ] 関連が強い要素は**狭く**、弱い要素は**広く**離しているか
- [ ] ベースラインで縦のリズムが揃っているか
- [ ] 任意ピクセルが混入していないか
- [ ] スマホで**画面端のセーフエリア**を確保しているか
