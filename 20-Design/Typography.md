# タイポグラフィ

## 一行で

> 文字は「**読む対象**」と「**見る対象**」の両面を持つ。タイポグラフィは**意味の運び方**を決める設計。

## なぜ重要か

UI における**95% の情報は文字**です。文字が読みづらければ、いかに美しいレイアウトも UX の基礎を欠きます。逆に、優れたタイポグラフィは「気づかれない」が、読み手の理解と滞在を支えます。

## 中核となる原理

### 1. 可読性 (Readability) と 視認性 (Legibility)

- **Legibility**: 個々の文字が他と**識別**できるか (`I` `l` `1` の区別等)
- **Readability**: 連続した文章を**疲れず読める**か(行送り・行長・コントラストの総合)

両者は別物。スコア表示用に作られた等幅フォントは Legibility は高いが長文 Readability は低い。

### 2. 行長 (Measure)

**1 行 45〜75 字**が読みやすさのスイートスポット(英文。日本語なら **35〜45 字**)。短すぎると視線がジャンプし、長すぎると次の行頭を見失う。

```css
.prose { max-width: 65ch; }  /* ch = 0 の幅。フォント追従 */
```

### 3. 行送り (Line Height)

本文は **1.4〜1.6** が目安。見出しは **1.1〜1.3**(行が短いので詰まっていてよい)。日本語は欧文より高めが読みやすい(画数密度が高い)。

### 4. タイプスケール

全要素のサイズが**比率で連鎖**する数列。比率の例:

| 比率 | 名称 | 用途 |
|---|---|---|
| 1.067 | Minor Second | 同音的、控えめ |
| 1.125 | Major Second | UI の本文用 |
| 1.250 | Major Third | 一般的なドキュメント |
| 1.333 | Perfect Fourth | 表現力のある UI |
| 1.500 | Perfect Fifth | ヘッドライン強め |
| 1.618 | Golden Ratio | 雑誌的・ドラマチック |

```
本文 16 → 18 → 21 → 24 → 28 → 32 → 36 …  (比率 1.125)
```

タイプスケールは**最低限**として運用し、その間の任意値を使わない(規律 = 一貫性)。

### 5. ウェイトとイタリック

- 強調は **bold か italic** のどちらかひとつ
- bold は **300 → 700** より **400 → 700** のジャンプの方が視認的に効く
- 多種ウェイトを並べるよりも **2〜3 ウェイト** に絞ったほうが上品

### 6. カーニング・トラッキング

- **カーニング**: 個別文字対の間隔(例: `AV`, `Ta`)
- **トラッキング**: 全体的な字間
- 大きい見出しほど詰める、小さい本文は**少しゆるめる**(8pt 以下なら +1〜2%)

### 7. 大文字 (UPPERCASE) の扱い

- 注意喚起になるが**読み速度が下がる**(大文字は形が均質)
- ボタン・ラベル等の**短い句**にとどめ、文章には使わない
- トラッキングは +5〜10% するとバランスする

## 日本語タイポグラフィの特殊事情

- **ウェイト感**: 漢字は黒く、ひらがなは軽い → 同じ Regular でも「黒さ」が違う
- **約物**(句読点・括弧)と前後の文字の**詰め**が美観を左右
- **ベタ組み**(均等字送り)が標準だが、見出しは詰めると締まる
- **字面率**: フォントによって字面の大きさが違うため、欧文と並ぶときサイズ調整が必要

## フォント選定の指針

1. **目的を定義** — 本文長文? 見出し? UI ?
2. **ウェイトの揃い**: Regular / Medium / Bold が揃うか
3. **字種**: 必要言語、数字、記号、絵文字
4. **ライセンス**: Web 配信可? 商用可?
5. **フォントファミリのペア**: 見出し用 + 本文用 を 2 種以内に
6. **可変フォント** (Variable Font) — ウェイトを連続調整できる、ファイル数を減らせる

## アンチパターン

- 同一画面に 4 種以上のフォント
- 本文が **14px 未満**(モバイルでは特に避ける)
- 行長 100 字超(長文 UI)
- 中央揃えの長文(行頭が揃わず疲れる)
- 装飾フォントを本文に
- 欧文フォントで日本語の代替が中華フォントになる(`font-family` 末尾に日本語フォントを必ず指定)
