# 視覚階層 (Visual Hierarchy)

## 一行で

> 「**何を最初に見せ、何を後にするか**」を意図的に設計する。階層が無ければ画面は等価なノイズになる。

## なぜ重要か

人は画面を**読まずに走査**します。最初の数秒で「ここが見出し」「ここが本文」「ここは補足」と暗黙に階層を認知できなければ、読み手は離脱します。階層は読み手の**ワーキングメモリへの贈り物**です。

## 階層を作る 6 つの軸

各軸は「**差**」を作ることで階層を生みます。**差は意味と一致**していなければなりません。

### 1. サイズ

最も強力。大きいほど目を引く。
- H1 は本文の **2〜2.5 倍**を起点に
- スケールには[[Typography#タイプスケール|タイプスケール]]を使う

### 2. 太さ (Weight)

太字 = 重要。但し**多用すると効かなくなる**(全部強調 = 強調なし)。

### 3. 色

- 高彩度・暖色は前進、低彩度・寒色は後退
- アクセント色は「**画面に 1〜2 箇所**」が原則
- → [[Color-Theory]]

### 4. コントラスト

背景との明度差。
- WCAG AA: 通常テキスト **4.5:1**、大型テキスト **3:1**
- → [[../30-Interface/Accessibility#コントラスト|アクセシビリティ]]

### 5. 位置

- 上ほど重要、左ほど早く読まれる(横書き言語)
- F パターン / Z パターンの視線軌跡を意識

### 6. 余白 (Whitespace)

要素の周りの空白が**重要度**を語る。プレジデンシャルな見出しは広い余白に**ぽつん**と置くだけで王様になる。
- → [[Spacing-Rhythm]]

## 階層の崩れ方(アンチパターン)

### 平坦化 (Flatness)

「全部大事」と訴えると、**何も大事ではなくなる**。
- 太字だらけ
- 全部に色がついている
- アラートの種類が多すぎて目が慣れる

### 二重メッセージ

サイズは大きいが色は地味、位置は端だが太字…のように**軸が矛盾**すると読み手が迷う。**軸を揃える**:重要なものは大きく・濃く・上に。

### サイズだけに頼る

サイズの差だけでは弱い。色・余白・位置と**重ねる**ほど階層は揺るぎなくなる。

## 走査パターンと最初の 3 秒

### F パターン

長文ページ(ブログ・記事)で典型的に観察される。**左端と冒頭**が読まれる。
- 左寄せ、見出しを情報の入口に置く
- リード文を冒頭に集約

### Z パターン

ランディングページなどシンプルな画面。左上 → 右上 → 左下 → 右下。
- ロゴを左上、CTA を右上 / 右下に置く

### Gestalt の原則

- **近接**: 近いものは関連すると見られる
- **類似**: 形・色が似ていれば関連
- **連続**: 並びで流れを作る
- **閉合**: 不完全でも形を補完する
- **共通運命**: 同方向に動くものは仲間

→ レイアウトでは「**何をグルーピングしたいか**」を Gestalt で表現する。

## 実践のチェック

階層が機能しているかは、以下で簡易テストできます:

1. **5 秒テスト**: 5 秒見せて閉じ、何が伝わったか聞く
2. **目を細めて見る**: 細部が消え、明暗の塊だけが残る。**重要要素が塊として浮き上がるか**
3. **白黒で見る**: 色を抜いてもレイアウトとサイズで階層が成立しているか
4. **読み順をなぞる**: 自分の指で目線を辿り、自然な順序か確認

## 実装への落とし込み

```css
/* 階層は CSS でも宣言可能 */
:root {
  --font-size-h1: 2.5rem;
  --font-size-h2: 2rem;
  --font-size-h3: 1.5rem;
  --font-size-body: 1rem;
  --font-size-caption: 0.875rem;

  --weight-bold: 700;
  --weight-medium: 500;
  --weight-regular: 400;
}
```

→ [[Design-Tokens]]、[[../40-Bridge/Design-Code-Handoff]]

## チェックリスト

- [ ] **5 秒で**主要メッセージが伝わるか
- [ ] **目を細めて**重要要素が浮き上がるか
- [ ] サイズ・色・位置の軸が**矛盾していない**か
- [ ] アクセント色は **1〜2 箇所**に絞っているか
- [ ] 太字・色強調を**使いすぎて麻痺**していないか
