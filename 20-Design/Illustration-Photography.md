# イラストレーションと写真ディレクション

## 一行で

> 視覚コンテンツの**選択と統一**は、UI のロジックと同じくらいブランドを決める。「あったほうがいい絵」ではなく「**この方向に統一されている画**」を持つ。

## なぜ重要か

写真・イラスト・3D レンダ ── 視覚アセットは**最も先にユーザーの目に入る**要素。雑な選定は:
- 全体の温度がブレる(プロらしくない)
- ステレオタイプ・偏った表現
- ストックっぽさ(他社と区別がつかない)
- 重い・遅い

良いビジュアルディレクションは**ブランドの個性**になり、長く使える。

## アセットの種類とトレードオフ

| 種類 | 強み | 弱み |
|---|---|---|
| **写真** | リアル、信頼感、感情移入 | 撮影コスト、多様性確保困難 |
| **イラスト** | 抽象化、ブランド色追従、面白い | 制作コスト、技法が古びる |
| **3D レンダ** | 自由度、リアル+柔軟 | 高コスト、生っぽいと不気味 |
| **アイコン** | 軽量、明示的 | 表現力限定 → [[Iconography]] |
| **生成 (AI/手続き)** | スケール、個別化 | 品質ばらつき、倫理 |
| **アニメーション** | 動きで伝える | 重い、装飾になりがち |

役割で**混ぜる**。「**画はすべてイラスト**」「**写真だけ**」と一律にしないが、**支配する 1 種類**を決める。

## 写真ディレクション

### 1. ライティング

- 自然光 (柔らかい、Instagram 風)
- スタジオ照明 (硬い、プロダクト撮影)
- 影の方向と濃度
- 全カットで**統一**

### 2. 色温度

暖色 (3000K) ─ 冷色 (6500K) のどこに揃えるか。雑誌的なら**温かみ**、テック的なら**ニュートラル〜寒**。

### 3. 構図

- 三分割法
- 中央配置(対称、強い)
- ネガティブスペース
- 視線の方向(被写体が**見る方向**にスペース)

### 4. 被写体の距離

- ロングショット(環境・文脈)
- ミディアムショット(人物 + 動作)
- クローズアップ(感情)
- マクロ(質感)

「全部クローズアップ」は息苦しい、「全部ロング」は迫力ない。混ぜてリズムを作る。

### 5. 人物表現

- 多様性(年齢・人種・体型・障害・服装)
- ステレオタイプ回避(「家事 = 女性」「エンジニア = 若い男性」を避ける)
- 自然な表情(過剰スマイルは「ストック写真」感)
- 人物の顔を**切らない**(プライバシー的・心理的に)

→ [[../40-Bridge/Inclusive-Design]]

### 6. 環境

- リアル空間(現代的、共感)
- 抽象背景(プロダクトに集中)
- ブランドカラーを**衣服や小物**に仕込む

### 7. ポストプロダクション

- 色調補正の**統一トーン**(LUT を共有)
- フィルムグレイン
- コントラスト方向(柔らかい / 硬い)

### 8. 著作権

- ストック写真は**契約条件**確認(Unsplash, Pexels は寛容、Getty は厳しい)
- 商用利用、編集可否、人物リリース
- AI 生成画像の権利は**国 / 訓練データ**で議論中

## イラストディレクション

### スタイル軸

- **線**: 太/細、均一/筆圧
- **色**: フラット/グラデ、限定パレット/フル
- **形**: 幾何/有機、シンプル/詳細
- **陰影**: フラット/柔/硬
- **手描き感**: クリーン/ラフ
- **遠近**: 平面/アイソメトリック/3D

これらを**5〜7 軸で記述**してガイドに残す。

### スタイル例

- **Stripe** : 派手色グラデ + 抽象幾何 + 3D メタリック
- **Slack** : フラット + 鮮やか + キャラクター
- **Notion** : ペン画 + モノクロ近似 + ノスタルジック
- **Duolingo** : 平面ベクター + 鮮やか + キャラクター
- **Mailchimp** : 手描き風 + ユーモア + 多様な人物

### キャラクター

ブランド・マスコットは**強い記憶**を残す:
- 一貫した姿(ポーズの違いはあっても同一個体)
- 表情のバリエーション
- 状況依存(「祝う」「困る」「考える」)

### イラストレータの選び方

- ポートフォリオで**スタイル一貫性**を見る
- 商用契約・著作権譲渡の経験
- 量産可能か(キャンペーン用に 30 枚作れるか)
- スタイルガイドを書ける(後で他作家が継承可能か)

外注する場合、**1 セット作って終わり**でなく**ガイド + ソース**を納品物にする。

## アイソメトリック / 3D

立体的な抽象表現:
- スタートアップ・SaaS で 2018-2022 に大流行
- フラットの飽きへの反動
- 制作コスト高、AI ツール (Spline 等) で下がりつつ

陥りがち:
- 全部 3D で**識別不能**
- ブランドカラーが活きない

## 写真とイラストの混在

両方使うなら**役割分担**を明示:
- 写真 = 顧客事例、人物、本物の証拠
- イラスト = 概念、機能説明、ヒーロー

混ぜ方:
- 写真の上に**ベクター線図**をオーバーレイ(プロセス説明)
- イラストの中に**写真テクスチャ**(コラージュ)

## アニメーション

→ [[Motion-System]] / [[Creative-Coding-Canvas-WebGL]]

- **Lottie** で Web/iOS/Android 共通アニメ
- ヒーロー演出、空状態、成功演出
- 控えめに、`prefers-reduced-motion` で停止

## アクセシビリティ

→ [[../30-Interface/Accessibility]]

- すべての画像に `alt` テキスト(装飾なら `alt=""`)
- イラストでメッセージを伝える場合、**テキストでも併記**
- カラーパレットの**コントラスト**(画像の上のテキストが読めるか)

## パフォーマンス

→ [[../10-Coding/Performance]] / [[../40-Bridge/Sustainability]]

- WebP / AVIF
- `srcset` で解像度対応
- `loading="lazy"`
- 大きな写真は**LQIP / blurhash** で先行表示
- イラストは**SVG が軽い**(線画なら特に)
- アニメは Lottie / WebM (動画より軽い)

## ガバナンス

ブランドガイドに含める:
- 写真スタイル(撮影指示、ライティング、ポストプロ)
- イラストスタイル(線・色・形)
- 人物表現の指針(多様性、ステレオタイプ回避)
- 著作権ポリシー
- 申請フロー(新規アセット作成依頼)

→ [[Brand-Voice]] / [[Design-Systems]]

## アンチパターン

- ストック写真をそのまま使い**他社と同じ**
- イラストスタイルが**ページごとに違う**
- 多様性配慮が**マーケティングのみ**で実装で破綻
- 巨大画像で**LCP 悪化**
- 著作権を確認せず利用
- 人物の顔を**意図せず特定**(肖像権)
- AI 生成を**告知せず**使用

## チェックリスト

- [ ] アセットの**支配的種類**(写真 or イラスト)が決まっているか
- [ ] スタイル軸が**5〜7 個**で記述されているか
- [ ] 人物表現が**多様性に配慮**しているか
- [ ] 全アセットに **alt** が付いているか
- [ ] WebP/AVIF + `srcset` で配信しているか
- [ ] 著作権・商用利用可否が**明確**か
- [ ] ガイドが**将来の制作者**に継承可能か
