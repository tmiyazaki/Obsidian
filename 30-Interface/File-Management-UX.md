# ファイル管理 UX

## 一行で

> アップロード・整理・共有・検索 ── ファイルは「**ユーザーの所有物**」。失わせない、見つけさせる、共有させやすくする。

## なぜ重要か

ファイルはユーザーが**最も大事にする**データ:
- 仕事の成果物
- 思い出 (写真・動画)
- 大切な書類

雑な UX は信頼を一瞬で失う:
- 「アップロードできない」
- 「どこに保存されたか分からない」
- 「**消えた**」

ファイル UX は**信頼の前線**。

## 主要なシーン

### 1. アップロード

ドラッグ&ドロップ、ボタンクリック、コピペ:

```html
<input type="file" accept=".jpg,.png,.pdf" multiple />
```

```ts
// ドラッグ&ドロップ
dropzone.addEventListener("drop", (e) => {
  e.preventDefault();
  const files = [...e.dataTransfer.files];
  upload(files);
});
```

考慮:
- **複数同時** (`multiple`)
- **ファイル種類** の制限 + 表示 (`accept`)
- **サイズ上限** + 事前警告
- **進捗表示** (個別 + 全体)
- **失敗時のリトライ**(ネットワーク不安定)
- **巨大ファイル**は分割 (`Resumable Upload`, `tus`)

### 2. ブラウズ・整理

#### ビューモード

- **リスト**: 詳細(名前・サイズ・更新日・所有者)
- **グリッド**: サムネイル中心 (写真・動画)
- **ツリー**: 階層構造

ユーザーが切り替えられるように。

#### ソートとフィルタ

- 名前 / 更新日 / サイズ / 種類
- フィルタ: タイプ、所有者、共有状態、タグ
- → [[Tables-Data-Grids]] / [[Search-UX]]

#### サムネイル

- 画像: 自動生成
- PDF: 1 ページ目
- 動画: フレーム + ▶
- 音声: 波形
- ドキュメント: アイコン + プレビューテキスト

サムネイルが**強力な手がかり**になる(名前を覚えていなくても見つかる)。

#### フォルダ vs タグ

- **フォルダ**: 1 ファイル = 1 場所(物理的、シンプル)
- **タグ**: 1 ファイル = 複数タグ(柔軟、複雑)
- ハイブリッド: フォルダ階層 + タグ補助

「フォルダ vs タグ」は永遠の宗教論争。**ユーザーの慣れ**を尊重。

### 3. プレビュー

クリック = フルダウンロードでなく、**ブラウザ内プレビュー**:

- 画像 → 拡大表示 (←→ で前後、Esc で閉じる)
- PDF → ページめくり
- 動画 → インラインプレイヤー
- ドキュメント → 一部抜粋

プレビューで**用途が満たされる**ケースが大半。ダウンロードは選択肢に。

### 4. 共有

→ [[Permissions-UX]]

- 個別招待 (メール/ID)
- リンク共有 (公開範囲設定)
- 期限・パスワード保護
- 「閲覧のみ」「コメント可」「編集可」

### 5. ダウンロード

- 単一: 元ファイル
- 複数選択 → ZIP 圧縮
- 大容量はバックグラウンド + 完了通知

### 6. 削除と復元

- ゴミ箱 (Soft Delete) → 30 日後完全削除
- 「永久削除」は確認 + 取り消し不可を明示
- 共有中ファイルの削除は**他者にも影響**を警告

→ [[../10-Coding/Database-Design#Soft-Delete-vs-Hard-Delete]]

### 7. バージョン履歴

- 上書きで前の版が**自動保存**
- 履歴一覧: 誰が・いつ・どう変えたか
- 任意の版に**ロールバック**

→ [[Real-time-Collaboration#History]]

## 進捗と状態

### アップロード中

```
[ 📷 vacation.jpg ]   [▓▓▓▓▓░░░] 62%   3.4MB / 5.5MB    [✕]
```

- 1 ファイルごとに進捗バー
- 全体集計 (3 / 12 完了)
- 失敗時のエラーメッセージ + リトライ
- バックグラウンド継続(ナビゲーションしても続く)

### ダウンロード中

ブラウザのデフォルト UI に任せるか、アプリ内で進捗表示。

### 同期状態 (クラウド統合)

```
[ ✓ 同期済み ]  [ ⏳ 同期中... ]  [ ⚠ オフライン ]
```

Dropbox, Google Drive のようにファイルごと/全体で**現在状態**を見せる。

## 大容量ファイル

### Chunked Upload

ファイルを分割 → 各 chunk アップロード → 失敗 chunk のみ再送:

```ts
const CHUNK_SIZE = 5 * 1024 * 1024; // 5MB
for (let start = 0; start < file.size; start += CHUNK_SIZE) {
  const chunk = file.slice(start, start + CHUNK_SIZE);
  await uploadChunk(chunk, start);
}
```

ライブラリ: `tus`, `Uppy`, `Resumable.js`。

### 並列アップロード

複数 chunk を**並行**で送る(帯域フル活用)。
ただし**並列度に上限**(下流負荷)。

### バックグラウンドアップロード

`Service Worker` + Background Sync API でブラウザを閉じても継続。

## ドラッグ&ドロップの罠

→ [[Drawing-Direct-Manipulation]]

- ドロップ領域が**狭すぎ**
- フォルダドロップ未対応 (`webkitGetAsEntry()` でフォルダ展開)
- ドラッグ中の**フィードバック弱**(枠のハイライト等)
- スクロールと干渉

## ファイル種類の扱い

### 写真・動画ライブラリ

- EXIF (撮影日・場所・カメラ) で自動分類
- 顔認識でアルバム
- 重複検出
- Live Photos / RAW のサポート

### ドキュメント

- 全文インデックス → [[Search-UX]]
- 共同編集 → [[Real-time-Collaboration]]
- バージョン管理

### 構造化ファイル (CSV / Excel)

- プレビューで**表として表示**
- インポートウィザード(列マッピング)

## アクセシビリティ

→ [[Accessibility]]

- ファイル選択ダイアログは**キーボードで完結**
- ドラッグ&ドロップに**キーボード代替**
- 進捗を `aria-live` で読み上げ
- アイコン+ファイル名 (アイコンに `aria-hidden`)

## モバイル

→ [[Mobile-Patterns]]

- iCloud/Google Drive 連携
- カメラから直接撮影 → アップロード
- 写真アプリから選択
- バックグラウンドでの継続アップロード

## セキュリティ

→ [[../10-Coding/Security]] / [[../40-Bridge/Privacy-by-Design]]

- ウイルススキャン (アップロード時)
- ファイル種類**実体検証**(拡張子だけでなく magic number)
- 実行可能ファイルの制限
- Content-Type を**信用しない**(ユーザー指定)
- 公開リンクの**推測困難な ID**

```ts
// ❌ 連番 ID(他人のファイルを推測可能)
/files/123

// ✅ ランダム長文 ID
/files/AbCdEf123XyZ
```

## ストレージ最適化

→ [[../40-Bridge/Sustainability]]

- 重複排除 (同一ハッシュは 1 回保存)
- 古いファイルの**アーカイブ層**(S3 Glacier)
- 圧縮 (画像は WebP/AVIF への自動変換)
- ユーザーごとの**容量制限**と表示

## アンチパターン

- アップロード進捗なし (固まったように見える)
- 失敗時にリトライ手段なし → 最初からやり直し
- ゴミ箱なし、削除即消滅
- 共有設定が**気付かないうちに**変わる
- 大容量で**一括送信**してタイムアウト
- ファイル名に**特殊文字**で破綻
- アクセシビリティ未対応

## チェックリスト

- [ ] アップロード進捗が**個別 + 全体**で見えるか
- [ ] 大容量で**Chunked / Resumable** か
- [ ] **ゴミ箱 + 復元期間**があるか
- [ ] **バージョン履歴**があるか
- [ ] サムネイル + プレビューで**開かずに**確認できるか
- [ ] 共有状態が**見えるか**変えやすいか
- [ ] アクセシビリティ・モバイルで**完結**するか
- [ ] セキュリティ (種類検証、ID 推測困難) を満たすか
