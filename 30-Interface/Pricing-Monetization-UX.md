# 価格・課金 UX (Pricing / Monetization)

## 一行で

> 価格は「**ページにある数字**」ではなく「**ユーザーが選び、払い、続ける**体験**」。**信頼**が中心。

## なぜ重要か

優れたプロダクトでも価格 UX が悪いと:
- **離脱** (登録途中の脱落)
- **解約** (請求への驚き、複雑さ)
- **クレーム**(突然の値上げ、課金ミス)
- 規制リスク (定期購入の表示義務)

良い価格 UX は**ユーザー利益とビジネスを両立**する。最近の AI プロダクトの隆盛で**使用量ベース課金**が増え、設計の難度が上がっています。

## 価格モデル

### 1. Flat (定額)

```
Pro: ¥980/月
Team: ¥4,800/月 (5 人まで)
```

予測可能、シンプル。SaaS の伝統。

### 2. Per-Seat (ユーザー単位)

```
¥1,200/ユーザー/月
```

組織で線形にスケール。Slack, Notion, Linear。

### 3. Usage-Based (従量制)

```
$0.0015 / 1K トークン (入力)
$0.0075 / 1K トークン (出力)
```

実消費量で支払う。AWS, AI API, Twilio。

### 4. Hybrid (基本料 + 従量)

```
Base: ¥9,800/月 (10K リクエスト含む)
+ 超過: ¥1/リクエスト
```

下限保証 + 上限なしの**現代的標準**。Stripe Connect, OpenAI API。

### 5. Outcome-Based (成果連動)

```
$0.02 / 成功した予約
$0 / 失敗
```

ユーザー成果に連動。Calendly Premium, Intercom Resolution Bot。

### 6. Freemium

無料 + 有料プラン。**コンバージョン**設計が中心。

### 7. Open Source / Self-Hosted + クラウド

オープン版は無料、ホスト版は課金。Sentry, Plausible, Supabase。

## 価格表 (Pricing Page)

### 構造

```
[ ヒーロー: 価値提案 + 主要 CTA ]

[ プラン比較 (3-4 列) ]
   Free      Pro        Team       Enterprise
   ¥0        ¥980/月    ¥4,800/月  Contact

   Features  Features   Features   Features
   ...       ...        ...        ...

   [Start]   [Start]    [Start]    [Talk]

[ FAQ ]

[ ロゴ集 ・ ソーシャルプルーフ ]
```

### Comparison Table

機能対比表は**長くなりがち**:
- 主要 5-7 機能だけ**一覧**で
- 詳細は**展開可能**

```
✓ 機能 A
✓ 機能 B (Pro 以上)
─ 高度な機能 (展開)
   ✓ 機能 X
   ✓ 機能 Y
```

### Toggle (月次/年次)

```
[ 月次 | 年次 (-20%) ]
```

年次選択で**割引**が伝わる。複雑な計算は要らない。

### "Most Popular" バッジ

中央のプランに「**おすすめ**」「**最も人気**」を表示。アンカリング効果でその選択を促す。

ただし、**実態と一致**していること(嘘は規制対象)。

→ [[../40-Bridge/Ethical-Design]]

## 表示の詳細

### 通貨と地域

→ [[../40-Bridge/Internationalization]]

```
日本: ¥980 / 月 (税込)
US:   $7.99 / month
EU:   €7.99 / month (incl. VAT)
```

地域で**通貨と税込み/別**を切り替え。法的義務(日本は総額表示義務、EU は VAT 込み)。

### 期間と単位

```
✓ "¥980 / 月" (明確)
✗ "¥9,800" (なんの数字?)
✗ "$0.0015 / 1K tokens" (1 リクエストいくら?)
```

「**何が・いくら・どの単位**」を**3 秒で**理解できるか。

### 隠れたコスト

```
✗ 最終ステップで "+¥500 手数料"
✗ "無料" だがクレジットカード必須
✗ 自動更新を**目立たない**位置に
```

→ [[../40-Bridge/Ethical-Design]]

法的にも問題。日本の特定商取引法、EU CRD で明示義務。

## 使用量ベース UX (AI 時代の中心テーマ)

「**使った分だけ**」は便利だが**不安**を生む:
- 「いくら使った?」
- 「請求書が来てから初めて知る」
- 「気付いたらクレジット枯渇」

### リアルタイム使用量

```
[ 今月の使用量 ]
████████░░░░  75%
$30 / $40 (クォータ)

詳細:
  API 呼び出し: 1,234 / 5,000
  ストレージ: 3.2 GB / 10 GB

[ 明細を見る ]  [ プラン変更 ]
```

設定画面・ダッシュボード上部に**常時表示**。

### Soft Limit と Hard Limit

```
Soft Limit: $40 で警告メール
Hard Limit: $50 で利用停止
```

両方をユーザーが**設定可能**に。Hard 上限なしで「翌月 $1,000 請求」の事故を防ぐ。

### 予測表示

```
今月使用量: $30
予測終月: $42
予算: $40 ⚠
```

「このペースだと予算超過」を**事前に**伝える。

### 単位の親切翻訳

```
✗ "1.2M tokens"      ← よく分からない
✓ "約 800 ページ分"  ← 直感的
✓ "Slack 約 5,000 メッセージ相当" ← 比喩
```

専門単位は**親しみやすい換算**を併記。

## チェックアウト

### ステップを最小化

```
1. プラン選択
2. メール + 支払い情報
3. 完了
```

3 ステップ以下が理想。**会員登録**を後ろに回す(ゲスト購入)。

### ペイメント

- クレジットカード(必須)
- Apple Pay / Google Pay (タップ 1 つ)
- PayPal
- 銀行振込 (B2B)
- 暗号通貨 (限定的)

複数オプションで**離脱を減らす**。

### Stripe Checkout / Stripe Elements

組み込みコンポーネント。**PCI DSS 準拠**を Stripe 側で。

### Save / Auto-fill

- カード情報を**保存**(同意の上)
- ブラウザ autofill 対応 (`autocomplete="cc-number"`)

→ [[Forms-and-Input]]

### エラーハンドリング

```
✗ "決済エラー"            ← 何が悪い?
✓ "カードの有効期限が切れています。
   別のカードを使うか、カード情報を更新してください。
   [カードを更新]  [別のカードを使う]"
```

→ [[UX-Writing]] / [[../10-Coding/Error-Handling]]

## トライアルと無料枠

### Free Trial

```
30 日間無料 → 自動課金
```

注意:
- 開始前に**カード必須か**(Friction vs 質)
- 終了 N 日前に**通知メール**(規制要求の地域も)
- ワンクリックでキャンセル可能

### Free Tier (永続)

無料機能 + 有料機能。

```
無料: 3 プロジェクトまで
Pro: 無制限
```

「**無料でもしばらく使える**」が定着の鍵。

### Reverse Trial

最初の 14 日は**フル機能**、その後**無料枠に縮小**。
有料化を強制せず、価値を体感した後で判断させる。
Linear, Notion 等が採用。

## 解約 (Churn)

### 解約は容易に

→ [[../40-Bridge/Ethical-Design]]

```
✓ 設定 > サブスクリプション > 解約
✗ 電話必須
✗ 隠れた場所
```

法的義務(EU, US カリフォルニア、日本の特商法)。

### 解約フロー

```
[ 解約しますか? ]

✗ ばか正直に解約 → "本当に?" → "本当に本当に?" 連発

✓ 短い質問:
  "何が改善できれば続けられますか?"
  - 高すぎる → 割引提案
  - 機能不足 → ロードマップ提示
  - 一時的に休む → Pause オプション
  ...

[ それでも解約 ]
```

**Cancel Save** 機能。Netflix, Spotify がこのパターン。
ただし**強引な引き止め**は逆効果(ダークパターン化しない)。

### Pause / Downgrade

完全解約の前に:
- **一時休止**(月額停止、データ保持)
- **ダウングレード**(下位プランへ)

「**辞めずに済む**」選択肢を提供。

### データ持ち出し

解約時に:
- 全データのエクスポート
- 完全削除リクエスト

→ [[../40-Bridge/Privacy-by-Design]]

## アップセル / クロスセル

### 自然な誘導

```
[ あなたの使用量が無料枠の 80% を超えました ]
[ Pro プランに切替 → 制限解除 + 機能 X が使えます ]
```

押し付けでなく**価値が明確**な誘導。

### Empty State での提示

→ [[Onboarding-Empty-States]]

「この機能を使うには Pro が必要」を**機能の入口で**自然に表示。

## B2B 特有

### 見積もり / 請求書

エンタープライズは**カード一括払い**でなく**請求書**:
- 見積もり生成
- 月次請求書 PDF
- 振込・小切手対応
- カスタム税率(VAT, 消費税)

### 複数年契約・カスタム条件

セールス相談が必要な大型契約:
- "**Contact Sales**" CTA
- フォームから問合せ

### 支払い者 vs 利用者

買い手と使い手が違う(IT 部門が支払い、現場が使う):
- 管理者ダッシュボード(請求・利用状況)
- 個別ユーザーには**請求情報を見せない**

### SSO / 監査ログ

→ [[Permissions-UX]] / [[../10-Coding/Multi-tenancy]]

エンタープライズプランで提供されることが多い。

## 設計の倫理

→ [[../40-Bridge/Ethical-Design]]

避けるべきパターン:
- "Confirmshaming" (「節約のチャンスを失う」拒否ボタン)
- 隠れた自動更新
- 解約困難
- 価格変更の事前告知なし
- 試用 → カード課金の罠
- 子ども向けに**ガチャ**

→ EU の Digital Services Act, FTC Click-to-Cancel ルール

## A/B テスト

価格は**最も影響度の高い**A/B テスト領域。
ただし:
- 一部ユーザーだけ違う価格 = **不公平感**(発覚リスク)
- 心理的価格(¥9,800 vs ¥10,000)で実際の差
- 短期 KPI 改善が**長期 LTV 悪化**を呼ぶことも

→ [[../40-Bridge/Discovery-and-Validation]]

## 計測

- コンバージョン率(訪問 → 登録 → 課金)
- ARPU (Average Revenue Per User)
- LTV / CAC 比
- Churn rate
- アップグレード率
- 解約理由分布

→ [[Dashboard-Design]]

## アクセシビリティ

→ [[Accessibility]]

- 価格表は**意味的 HTML** (`<table>`, `<th>` で機能比較)
- 「最も人気」バッジは**視覚 + テキスト**両方
- フォームは標準のフォーム規律
- 通貨記号は SR で**読まれる**形式

## アンチパターン

- 隠れた料金(チェックアウト最終で発覚)
- 単位が**意味不明** (1.2M tokens って何?)
- 自動更新を**目立たない**
- 解約が**3 階層下**
- 機能比較表が**X だらけ**(肯定的に)
- "Free" だが実際は**カード必須**
- 使用量上限**なし** → 課金事故
- B2B プランの「Contact Sales」しかない(価格不透明)

## チェックリスト

- [ ] 価格・期間・単位が**3 秒で**伝わるか
- [ ] 隠れたコストが**ない**か
- [ ] 使用量ベースなら**リアルタイム表示 + 上限設定**があるか
- [ ] 解約が**1 クリックで**できるか
- [ ] 失敗時のエラーが**何が悪いか・どう直すか**を伝えるか
- [ ] 通貨・税表示が**地域に適合**しているか
- [ ] 規制 (定期購入表示・サブスク解約) を満たすか
- [ ] アクセシビリティ・モバイルで完結するか
