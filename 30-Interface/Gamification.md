# ゲーミフィケーション

## 一行で

> ゲームの「**やる気を維持する仕組み**」を**非ゲーム文脈**に取り入れる。ただし「**ポイントを置けば動機づく**」は誤解。

## なぜ重要か

学習・運動・健康・業務など、ユーザーが「**続けたい**」を支えるのが UX の重要課題:
- Duolingo の連続学習
- Strava の達成バッジ
- GitHub の Contribution Graph
- Apple Watch のアクティビティリング

雑なゲーミフィケーションは:
- ポイントだけ追って**意味がない**
- 操作的・搾取的に感じる
- 短期で飽きて離脱

良い設計は**内発的動機**を支える。「外発的報酬で操作する」ではなく。

## 動機の分類 (Self-Determination Theory)

ユーザーが行動する理由は 3 種:

### 1. Autonomy (自律性)

「**自分が選んだ**」感覚。
- カスタマイズ可能なゴール
- スキップ可能
- 自分のペース

### 2. Competence (有能感)

「**できるようになっている**」実感。
- 適切な難易度
- 進捗の可視化
- 段階的な習得

### 3. Relatedness (関係性)

「**仲間と繋がっている**」感覚。
- 共同チャレンジ
- 成果の共有
- 互いの応援

外発的報酬 (ポイント・バッジ) は**短期効果**しかない。3 要素を満たす設計が長期動機を生む。

## 主要なゲーム要素

### 1. ポイント・スコア

- 行動の累積評価
- 単独では意味薄(何のためのポイント?)
- 「**何を測っているか**」が明確であること

### 2. レベル・ランク

進捗の段階。
- 経験値 → レベルアップ
- ブロンズ・シルバー・ゴールド
- 直線的でなく**段階的に難しく**

### 3. バッジ・実績

- 「**初めて X した**」
- 「**N 回 Y した**」
- 隠しバッジで発見の喜び
- 自慢できる(プロフィール表示、SNS シェア)

過剰なバッジは**価値が薄まる**。意味あるマイルストーンに絞る。

### 4. 連続記録 (Streak)

毎日続けること = 価値:
- Duolingo の毎日学習
- Apple Watch の活動リング
- Wordle の連続正解

注意:
- 1 日逃すと**全部消える**は厳しすぎる(復活アイテム、Streak Freeze)
- 連続を**強迫**にしない(健康への影響)

### 5. リーダーボード

他者との比較:
- グローバル(刺激強だが弱者は離脱)
- フレンド限定(現実的)
- 同レベル同士(競争を楽しめる)

注意:
- 全員に**勝てる人がいる**ような設計
- 上位者だけが見えると**底辺は見えなくなる**(セグメント化)

### 6. クエスト・ミッション

「**今日 / 今週これをしよう**」:
- 小さな達成感
- 慣れた操作の確認
- 新機能の発見導線

### 7. プログレスバー

「あと**少しで**完成」の心理を活用 (ゴール勾配仮説):
- 50% 表示より 70% 表示のほうが**やる気が出る**(同じ作業量でも)
- 達成した瞬間の演出

### 8. リワード (報酬)

予測可能 / 予測不能:
- **予測可能**: 「N 回で確実にもらえる」
- **予測不能**: ガチャ、変動報酬(ドーパミン強)

予測不能は**依存性**を生むため**慎重に**(下記 Ethics 参照)。

### 9. ストーリーライン

物語の中で進むと感情移入:
- キャラクターが応援する (Duolingo の Duo)
- 章立て(オンボーディング → 中級 → 上級)
- イベント(季節限定)

### 10. 共同 / 対戦

- ギルド・チームでの目標
- リアルタイム協働
- PvP

### 11. 通貨・経済

ゲーム内通貨(ポイント)で**何かと交換**:
- 学習継続 → ハート (Duolingo)
- ポイント → カスタマイズアイテム
- ジェム購入(課金)

経済が破綻すると一気に魅力が消える(インフレ)。

## 適用領域

### 学習・スキル習得

- Duolingo, Khan Academy, Memrise
- 連続記録、レベル、チャレンジ

### 健康・運動

- Apple Fitness, Strava, Fitbit, Pokémon Go
- アクティビティリング、ライバル、バッジ

### 業務・生産性

- Habitica, Forest, Todoist Karma
- タスク完了で経験値、ストリーク

### 金融・節約

- 貯金チャレンジ、投資の達成感

### 環境・社会貢献

- 「N 人がリサイクルした」
- ボランティア記録

### B2B SaaS

- HubSpot のゲージ
- Stripe のテストモード進捗
- Notion の Slack-like emoji 反応

「業務でゲーミフィケーションは合わない」は**誤解**。控えめに、目的に合うなら効く。

## 設計原則

### 1. 内発的動機を補助する

ユーザーが**本当にやりたい**ことを支える。
「ポイントが欲しいだけ」になったら設計失敗。

### 2. 学習の段階に寄り添う

- 初心者: 容易な勝利、頻繁なフィードバック
- 中級者: 適度な挑戦
- 熟練者: 深い達成、自由度

「**Flow チャネル**」(難易度と能力のバランス)を保つ。

### 3. 失敗の処理

- 失敗が**続けられる**ように設計
- 完璧主義を避ける(連続記録の救済策)
- 「3 日サボったから諦める」を起こさせない

### 4. 多様な達成

「全員がトップ」は無理だが、「**自分なりの達成**」は可能:
- 個人的記録 (PB)
- 多軸の指標(速さ・正確さ・量)
- 隠れた挑戦

### 5. 透明性

なぜポイントがついたか、なぜバッジがもらえたか**明確に**。
ブラックボックスは不信を生む。

### 6. オプトアウト

ゲーミフィケーション要素を**切れる**ことが大事:
- バッジ通知が嫌なユーザー
- 競争を楽しめないユーザー

## 倫理 (Dark Pattern との境界)

→ [[../40-Bridge/Ethical-Design]]

ゲーミフィケーションは**ダークパターンに容易に堕ちる**:

- **依存設計**: ガチャ、変動報酬、無限スクロール → ドーパミン操作
- **失われる恐怖** (Loss Aversion): 「Streak が消える」で強迫
- **時間搾取**: 一日中ログインさせる
- **社会比較の悪用**: 友人より下になる不安

子ども・若者を対象にする場合は特に慎重に。EU/UK で規制が進む。

## 計測

- DAU / WAU の伸び
- リテンション (Day 1 / Day 7 / Day 30)
- セッション時間と頻度
- 達成バッジの分布(取得しすぎ・少なすぎ)
- 離脱直前の状況

短期 KPI (滞在時間) より**長期定着**(月後アクティブ・満足度)を見る。

## アクセシビリティ

→ [[Accessibility]] / [[../40-Bridge/Inclusive-Design]]

- 連続記録は**休暇取得・病気**に配慮(自動 Pause)
- 競争を**苦手なユーザー**に押し付けない
- 視覚演出は **`prefers-reduced-motion`** 尊重
- 色だけで達成度を伝えない(数値・形併用)

## アンチパターン

- ポイントを**置いただけ**(意味薄)
- バッジが**何百個**で価値が消える
- 連続記録が**強迫的**
- リーダーボードで**初心者が絶望**
- 課金強制(無料では遊べない設計)
- 子ども向けに**ガチャ**
- 業務系で**遊び要素過剰**

## チェックリスト

- [ ] **内発的動機**(自律・有能感・関係)を支えるか
- [ ] バッジ・ポイントに**意味**(何の測定値か)があるか
- [ ] 失敗から**戻れる**設計か
- [ ] 全ユーザーに**到達可能な達成**があるか
- [ ] 操作的・依存的でない (ダークパターン回避)
- [ ] **オプトアウト**できるか
- [ ] アクセシビリティ・休暇への配慮があるか
