# 地図と位置情報 UX

## 一行で

> 地図は「**世界を見せる窓**」。ズーム・パン・レイヤ・ピン・経路 ── 独自の語彙とパターンを持つ UI。

## なぜ重要か

地図は配車・配達・不動産・観光・物流・ナビ・データ分析の**中核 UI**:
- Uber / Lyft (配車)
- Airbnb (検索)
- Google Maps (移動)
- DoorDash (配達追跡)
- Zillow (不動産)
- Strava (アクティビティ)

雑な実装は:
- 操作不能 (タップ精度・ジェスチャ衝突)
- パフォーマンス崩壊 (大量ピン)
- バッテリー枯渇 (位置情報常時取得)
- プライバシー漏洩

## 基本パターン

### 1. パン・ズーム

```
- ピンチ: ズーム
- ダブルタップ: ズームイン
- 二本指ダブルタップ: ズームアウト
- 一本指ドラッグ: パン
- 二本指回転: 地図回転
- 二本指上下スワイプ: 3D 傾き
```

ジェスチャは**慣習に従う**(Google Maps / Apple Maps 系)。

### 2. ピン (マーカー)

```
[ 🚩 ロケーション名 ]
```

- クラスタリング(密集時は数字で集約)
- 種類で色分け
- 状態で形変化 (空き/満)
- タップで詳細パネル

### 3. ポップオーバー / カード

ピンタップで:

```
[ レストラン名 ]
[ ★★★★ 4.2 (120 件) ]
[ 営業中 - 22:00 まで ]
[ 詳細を見る ]
```

地図上にポップオーバー or 下からシート(モバイル)。

### 4. 検索バー

```
[ 🔍 場所・住所・店名... ]
```

- 入力中のサジェスト
- 地理的バイアス (現在地・表示中エリア)
- カテゴリ検索 (「コーヒー」「ガソリンスタンド」)

→ [[Search-UX]]

### 5. ルート / 経路

```
A → B
   🚶 25 分 / 🚴 10 分 / 🚗 8 分

詳細:
1. 国道 1 号を北へ 500m
2. 右折して...
```

- 移動手段の切替
- 代替ルート
- 渋滞・通行止め情報
- 距離 / 時間

### 6. レイヤ切替

```
[ 標準 ] [ 衛星 ] [ 地形 ]
[ ✓ 公共交通 ] [ ✓ 自転車道 ]
```

複数情報を**重ね合わせ**。

### 7. 範囲指定

```
- 矩形ドロー
- 多角形ドロー
- 半径ドラッグ
- 距離 / 面積測定
```

不動産・配送エリアで定型。

## モバイル特有

→ [[Mobile-Patterns]]

- **ボトムシート**: 検索結果、ナビ詳細
- 親指範囲に主要操作
- セーフエリア(ノッチ・ホームバー)
- スクリーンロックでもナビ継続

```
[ Map ]
[ ━ ボトムシート ━ ]
[ 検索結果 / ルート詳細 ]
```

### Compass + Heading

```
[ 北 ↑ ]    リセットボタン
```

ユーザーの**向き**(コンパス)で地図が回転。
回転が**酔いを誘う**ので、固定モードも提供。

## ジオフェンス

特定範囲に入った / 出た時に動作:
- 「会社の近くで遅刻通知」
- 「店舗近くで割引クーポン」
- 「家を出る時にタスクリマインダ」

iOS / Android 標準 API + Background Location 許可必須。

## 位置情報の取得

```ts
navigator.geolocation.getCurrentPosition(
  (pos) => console.log(pos.coords),
  (err) => console.error(err),
  { enableHighAccuracy: true, timeout: 5000 }
);

// 連続監視
const watchId = navigator.geolocation.watchPosition(...);
```

精度:
- 屋外 GPS: 5-10m
- 屋内: 10-50m
- WiFi 三角測量: 数十 m

許諾を**価値提示後**に取る(起動直後の連続許諾は禁忌)。

→ [[Sensor-Camera-Haptics]] / [[../40-Bridge/Privacy-by-Design]]

## バッテリー

リアルタイム位置追跡は**バッテリー食う**:
- 高精度 (GPS 常時): 数時間で枯渇
- 低精度 (セルラー): 半日持つ
- バックグラウンド: OS が制限

戦略:
- 必要なときだけ高精度
- 動きが少ない時は間隔を空ける
- 「**省電力モード**」を提供

→ [[../40-Bridge/Sustainability]]

## 主要ライブラリ・API

### Google Maps Platform

業界標準、高機能、有料 (使用量ベース)。
SDK が iOS / Android / Web 揃う。

### Mapbox / MapLibre

カスタマイズ性高、スタイル設計自由。
MapLibre は OSS フォーク (Mapbox の有料化に対応)。

### OpenStreetMap (OSM) + Leaflet

無料、コミュニティ製。商用は注意。

### deck.gl

Uber 製、**大量データ可視化**に特化。
WebGL でレンダリング。

### Apple MapKit

iOS / macOS で美しい統合。

### Google Maps Embed

iframe で埋め込み。最も軽い。

## データ可視化との統合

→ [[../20-Design/Data-Visualization]] / [[Dashboard-Design]]

### Choropleth (色塗り)

地域を**色濃度**で:
- 選挙結果、人口密度、GDP

### Heatmap

点の密度を熱で表現:
- 犯罪、Wi-Fi スポット、観光客

### Flow Map

A → B の移動を**線**で:
- 物流、通勤、移民

### 3D 棒グラフ on Map

地域ごとの値を**柱の高さ**で:
- deck.gl で実装

注意: 高い柱が**他を隠す**問題。視点切替必須。

## 検索 + 地図

→ [[Search-UX]]

「**地図に表示中の範囲**」で検索結果フィルタ:

```
[ 検索: ラーメン ]
[ "東京駅周辺" を検索 → 地図上のピン + リスト ]
```

地図移動で結果が**追従**(または再検索ボタン)。

Airbnb の「Search this area」ボタンが好例。

## アクセシビリティ

→ [[Accessibility]]

地図は SR で**読めない**:
- 主要情報の**テキスト代替**を提供
- 「現在地から半径 500m に 5 件」のような要約
- キーボードナビ(矢印キーでピン移動)
- ハイコントラストモード

スクリーンリーダーで操作可能な代替フロー(リスト UI)を**必ず**用意。

## 国際化

→ [[../40-Bridge/Internationalization]]

- ラベル言語 (自動 / ユーザー設定)
- 単位 (km / miles)
- 住所形式 (国別)
- 地図中の名称 (北京 / 北京市 / Beijing)
- 国境表示 (政治的に繊細)

国境は**地域論争**があり、Google Maps は**閲覧者の国に応じて**変える。

## オフライン地図

→ [[../40-Bridge/Local-First-Sync]]

ダウンロードで**オフライン利用**:
- 旅行者
- ナビ (圏外でも動く)
- 配送ドライバ

- タイル (PNG/Vector) を端末保存
- 検索 / ルート探索もローカル

Mapbox / Google Maps の SDK が対応。

## プライバシー

→ [[../40-Bridge/Privacy-by-Design]]

位置情報は**極めて個人情報**:
- 行動履歴
- 居住地・職場
- 家族・宗教施設訪問

設計の鉄則:
- **必要時のみ**取得
- **精度を最低限**に(国・市レベルで十分なら GPS 不要)
- 保管期間を明示
- ユーザーが**履歴を見られる・削除できる**
- 第三者と共有しない (規制対象)

iOS の「**1 回だけ許可**」「**おおよその位置**」設定を尊重。

## エラーと精度

```
[ ⚠ 位置情報が取得できません
   - GPS をオンにしてください
   - 屋内では精度が落ちます ]
```

- 精度を**ユーザーに示す**(±50m 等)
- 古い位置を「**N 分前**」と明示
- 失敗時は手動入力にフォールバック

## デザイン要素

### カラー

→ [[../20-Design/Color-Theory]]

地図ベースは**抑える**(コンテンツが上に乗るため):
- 淡いグレー / ベージュ
- 道路は**主要色を 1 つ**

UI 要素 (ピン、線) は**鮮やか**にコントラスト。

### タイポグラフィ

→ [[../20-Design/Typography]]

- 地名は**読みやすい**サンセリフ
- 国境を超える時に**言語切替**
- ズームレベルで**情報密度**を変える

### モーション

→ [[../20-Design/Motion-System]]

- スムーズパン (慣性)
- ズームイン/アウトのアニメ
- ピン出現の段階アニメ
- ナビの**次の交差点**で予兆アニメ

## アンチパターン

- 大量ピン (1000+) をクラスタなしで表示
- 位置情報を**起動直後**に要求
- バックグラウンド常時 GPS
- ユーザー位置を**サーバに常時送信**
- 検索結果がリストにあるが**地図に出ない**
- モバイルで**スクロールと地図ジェスチャ**が衝突
- SR で操作**完全不可能**
- 国境問題で**特定地域から非表示**

## チェックリスト

- [ ] 大量ピンを**クラスタリング**しているか
- [ ] 位置情報を**価値提示後**に要求しているか
- [ ] バッテリー消費を**最小化**しているか
- [ ] **オフライン**で何が動くか明確か
- [ ] **アクセシビリティ代替**があるか
- [ ] **プライバシー**(精度・期間・共有)が透明か
- [ ] 国際化(言語・単位・住所形式)対応か
- [ ] モバイルで**ジェスチャ衝突**しないか
