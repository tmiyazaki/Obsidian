# 設定と環境設定 (Settings)

## 一行で

> 設定は「**全機能の倉庫**」ではなく「**ユーザーが自分の体験を調整する場**」。発見しやすく、誤って壊せず、回復可能に。

## なぜ重要か

設定画面は機能が増えるほど**ゴミ箱化**しやすい。「とりあえずここに」と項目が積まれ、ユーザーは:
- 必要な設定が**見つからない**
- 触ると**何が起きるか分からない**
- 元に戻せない

逆に良い設定 UI は、プロダクトの**柔軟性**と**信頼性**を象徴します。

## 設定とプリファレンスの違い

| 設定 (Settings) | 環境設定 (Preferences) |
|---|---|
| 動作 / 機能の構成 | 個人の好み |
| 通知 ON/OFF, 連携アカウント | テーマ, 言語, ショートカット |
| ワークスペース全体 | 個人 |

両者は**分離**しておくと、UI の整理が楽。

## グルーピング

ユーザーが探しやすい単位で:

```
┌─ アカウント ──────────────────┐
│  プロフィール                  │
│  メール / パスワード           │
│  サブスクリプション             │
└─────────────────────────────┘

┌─ 環境設定 ────────────────────┐
│  外観 (テーマ・密度)           │
│  言語 / 地域                  │
│  キーボードショートカット       │
└─────────────────────────────┘

┌─ ワークスペース ───────────────┐
│  メンバー                      │
│  権限                          │
│  連携 (Slack, GitHub...)       │
└─────────────────────────────┘

┌─ 通知 ────────────────────────┐
│  プッシュ                      │
│  メール                        │
│  サマリ                        │
└─────────────────────────────┘
```

カテゴリ数は **5〜8 個まで**が目安。それ以上は階層を作る。

## ナビゲーション

### サイドバー

```
[ アカウント         ]
[ 環境設定           ]
[ ワークスペース ▼   ]
   メンバー
   権限
   連携
[ 通知              ]
[ 課金              ]
```

設定数が多い SaaS の標準。

### タブ

カテゴリが少なければ上部タブ。モバイルでは破綻するので注意。

### 検索

設定が多いプロダクト (Slack, Notion, VS Code) では**設定検索**が必須:

```
[ 🔍 設定を検索: "通知" ]
   ↓
   - 通知 > プッシュ
   - 通知 > メール
   - ワークスペース > 通知設定
```

→ [[Search-UX]]

## コントロールの選び方

| 状況 | UI |
|---|---|
| ON / OFF | トグルスイッチ |
| 排他選択 (1 つだけ) | ラジオボタン |
| 複数選択 | チェックボックス |
| 複数項目から 1 つ | ドロップダウン |
| 数値範囲 | スライダ + 数値入力 |
| 短い文字列 | テキスト入力 |
| 長文 | テキストエリア |
| 色選択 | カラーピッカー |
| ファイル | アップロード |

### トグル vs チェックボックス

- **トグル**: 即座に効く設定 (`通知を有効にする`)
- **チェックボックス**: フォーム送信で保存される設定

両者を混在させると混乱。プロダクト全体で**一貫**して。

### 即時保存 vs 明示保存

#### 即時保存 (Auto-save)

トグル / 単純な選択。変更が**即反映**:

```
[ ✓ 通知を有効にする ]   ← クリックで保存
   ✓ 保存しました (トーストで確認)
```

#### 明示保存 (Save button)

複数フィールドを**まとめて**変更:

```
[ プロフィール ]
名前: [ Alice           ]
自己紹介: [ ...        ]
[ キャンセル ]  [ 保存 ]
```

複雑なバリデーション、プレビュー、未保存警告が必要なときは明示保存。

### 未保存の警告

明示保存方式で離脱しようとしたとき:

```
未保存の変更があります。
[ 破棄して移動 ]  [ 保存して移動 ]  [ キャンセル ]
```

ナビゲーション、タブ閉じ、リロード時に検出。`beforeunload` イベント。

## デフォルト設計

> **90% のユーザーがそのまま使える初期値**を選ぶ。

良いデフォルトは:
- 設定画面に入る理由を減らす
- 新規ユーザーが**何もしなくても動く**
- 望ましい挙動を**強化**する

例:
- 通知: 重要なものだけ ON
- テーマ: System (OS 追従)
- 言語: ブラウザ設定から推測
- プライバシー: 最も保守的

## 元に戻す手段

### Reset to defaults

カテゴリごとに「**初期値に戻す**」ボタン。確認ダイアログで影響範囲を明示。

### Undo

設定変更直後の Toast に「Undo」を提供。

### バージョン履歴

ワークスペース設定など重要な変更は履歴を残す (`変更ログ`)。

## 危険な設定

- アカウント削除
- ワークスペース削除
- API キー再生成
- 大量データのエクスポート / インポート

これらは:
- **ページの最下部**に配置 (誤クリック防止)
- 専用の **Danger Zone** セクション
- 確認: 名前を**手動入力**させる
- 不可逆性を**明示**

```
─ Danger Zone ────────────────
┌─ ワークスペースを削除 ─────────┐
│ この操作は取り消せません。       │
│ 全データ・全メンバーが失われます。 │
│                              │
│ 確認のため、ワークスペース名     │
│ "my-workspace" を入力してください│
│ [ ___________________ ]       │
│ [ ワークスペースを削除 ]        │
└─────────────────────────────┘
```

## 権限とロール

→ [[Permissions-UX]]

設定項目は**ロールごとに**表示制御:

- メンバーには「自分の通知」のみ
- 管理者には「ワークスペース通知」「メンバー管理」も
- 見えない設定は**完全に隠す**(無効化より)

## 同期と複数デバイス

- ユーザー設定はサーバーに保存し、**全デバイスで同期**
- デバイス固有設定 (テーマ、ショートカット) は**ローカル**または**両方選べる**
- オフラインで変更 → オンライン復帰時にマージ

## API キー / シークレット表示

```
API キー: sk-1234...XXXX  [ コピー ]  [ 再生成 ]  [ 削除 ]
        作成: 2026-01-15
        最終使用: 2 時間前
```

- 一度作成したキーは**初回のみ全文表示**(マスク後はコピー不可、新規発行)
- 使用ログを表示
- ローテーション機能

→ [[../10-Coding/Security]]

## 連携 (Integrations) UI

OAuth で外部サービスと連携:

```
[ Slack ]      ✓ 連携済み (連携: alice@workspace)  [ 切断 ]
[ GitHub ]     [ 連携する ]
[ Google ]     [ 連携する ]
```

切断時の影響を**事前に**説明 (「これを切ると通知が届かなくなります」)。

## モバイル設定

- 通知許可は**必要時に**プリ許諾 → OS ダイアログ → [[Notifications]]
- 位置情報・カメラ・連絡先など**OS 連携**は OS 設定画面へ誘導
- 本体設定 vs アプリ設定の境界を明示

## アクセシビリティ

→ [[Accessibility]]

- ラベルと `<input>` の紐付け
- トグルに `aria-checked` / `role="switch"`
- 危険操作に**確認 + 説明**を `aria-describedby` で
- フォーカス順序が論理的か
- スクリーンリーダーで「設定が保存されました」のフィードバック

## 検索可能性 / リンク可能性

- 各設定項目に**直接 URL** (例: `/settings/notifications/email`)
- 検索結果 / ヘルプから**直接ジャンプ**できる
- アプリ内ヘルプから「設定 X を変更」リンク

## アンチパターン

- 「その他」カテゴリにすべて詰める
- 設定変更が**何に影響するか**説明なし
- 即時保存と明示保存の**混在**で混乱
- 危険操作の**確認なし** + Undo なし
- モバイルで**サイドバーが消える**
- 全部 OFF にすると**プロダクトが使えなくなる**設計
- 設定検索なし (300 項目から目視で探す)

## チェックリスト

- [ ] カテゴリが**8 個以下**にまとまっているか
- [ ] **検索**で設定が見つかるか
- [ ] 各項目に**短い説明**があるか
- [ ] 即時保存 / 明示保存の方式が**一貫**しているか
- [ ] 危険な操作が**Danger Zone** に隔離されているか
- [ ] **デフォルト値**が 90% に合うか
- [ ] **権限**で表示が適切に分かれているか
- [ ] モバイルで**設定にたどり着ける**か
