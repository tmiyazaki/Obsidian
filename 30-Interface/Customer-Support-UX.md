# カスタマーサポート UX

## 一行で

> 「**困った時の体験**」は**通常時より記憶に残る**。サポート UX はプロダクトの信頼を作る最後の砦。

## なぜ重要か

サポートはコストセンタと見られがちだが:
- 解決体験で**顧客生涯価値 (LTV)** が変わる
- 悪い対応 → SNS 炎上
- 良い対応 → リピート + 推薦

支援すべき:
- セルフサービス (ヘルプ・FAQ)
- AI チャット (一次対応)
- 人間オペレーター (複雑案件)
- フィードバックループ (プロダクト改善)

「サポートに行かなくて済む UX」が最強だが、行ったときの**質**も重要。

## 主要チャネル

### 1. ヘルプセンター (Self-Service)

- 階層化された記事
- 検索 + サジェスト
- 関連記事リンク
- 「役に立ったか」フィードバック
- 更新日付

→ [[Search-UX]] / [[../40-Bridge/Documentation-as-Product]]

### 2. AI チャット / FAQ Bot

→ [[AI-LLM-Interfaces]] / [[Conversational-UI]]

```
[ Bot: お困りですか? よくある質問:
       [ ログインできない ]
       [ 注文の確認 ]
       [ 返品したい ]
       [ オペレーターと話す ] ]
```

クイックリプライ + 自然文入力。
**簡単な質問の 70% を解決**を目指す。

### 3. ライブチャット (Human)

```
[ オペレーターに繋がりました - Alice ]
```

- 営業時間表示
- 待ち時間目安
- ファイル添付
- 過去履歴

ライブラリ: Intercom, Zendesk, Crisp, Help Scout, Front。

### 4. メール

- 自動受付返信
- チケット番号
- 24-48h 以内の返信
- 解決後の満足度調査

### 5. 電話

- 高優先度・複雑案件
- 待ち時間表示
- コールバック予約

### 6. SNS / コミュニティ

- 公開フォーラム (Discourse, Reddit, Stack Exchange 形式)
- ユーザー同士の助け合い
- Brand チームの公式回答

### 7. 対面・現地

- リテール (Apple Store の Genius Bar)
- 出張サポート (BtoB)

## エスカレーションフロー

```
ヘルプ記事 (self-service)
   ↓ 解決しない
AI Bot (簡単な質問)
   ↓ 複雑
人間オペレーター (一次)
   ↓ 専門領域
専門スタッフ / エンジニア (二次)
   ↓ 重大
マネージャ / CEO エスカレーション
```

各段階で**コンテキストを引き継ぐ**(履歴を見せる)。
「**最初から説明し直し**」は最悪。

## トリアージ

優先度の自動判定:
- VIP 顧客 (有料プラン、大口)
- 緊急度 (アクセス不能 vs UI 改善要望)
- セキュリティ案件
- 退会要請

ML で自動分類 + 人間レビュー。

## サポートチケットの構造

```
チケット ID: #12345
件名: ログインできない
ステータス: 対応中
優先度: 高
担当: Alice
顧客: Bob (Pro plan, 顧客 ID 789)
タグ: auth, mobile

タイムライン:
  - 14:23 顧客が報告
  - 14:25 Bot が一次対応
  - 14:30 Alice が引き継ぎ
  - 14:45 解決法を提案
  - 14:50 顧客が確認
```

- 検索可能
- 関連チケットリンク (同じ問題が複数)
- 内部メモ (顧客非表示)
- 添付ファイル
- 過去履歴

## エージェント (オペレーター) 側 UX

サポートチームが使う管理画面:

### ダッシュボード

→ [[Dashboard-Design]]

- オープンチケット数
- 平均応答時間
- CSAT スコア
- 担当者の負荷分散

### チケット詳細画面

- 顧客情報 (プラン、利用履歴)
- 過去のチケット
- システム状態 (関連アラート)
- AI 提案 (回答案、関連記事)
- マクロ (定型応答)

「**3 秒で文脈を掴める**」設計が応答時間を桁で変える。

### マクロ・テンプレート

```
[ よくある質問 ]
- パスワード再設定の手順
- 返金ポリシーの説明
- メンテナンスの告知

[ ボタン 1 つで挿入 ]
```

ただし**機械的すぎる対応**は逆効果。**顧客名・状況を埋め込み**人間味を残す。

### AI 補助

- 関連記事のサジェスト
- 回答ドラフト生成
- 文体校正
- センチメント分析 (怒っている顧客に注意喚起)

→ [[AI-LLM-Interfaces]] / [[Agentic-AI-Patterns]]

## メトリクス

- **CSAT** (Customer Satisfaction Score): 「満足しましたか?」1-5
- **NPS** (Net Promoter Score): 「友人に推奨しますか?」0-10
- **First Response Time** (初回応答)
- **Resolution Time** (解決まで)
- **Ticket Volume**
- **Self-Service Rate** (人間到達前に解決)
- **Reopen Rate** (再オープン)

短期指標 (応答時間) と**長期指標** (CSAT, リテンション) の両方を見る。

## サポート文言

→ [[UX-Writing]]

### トーン

- **共感**: 「ご不便おかけして申し訳ありません」
- **明確**: 何が起き、何ができるか
- **次の一歩**: 待たせない、選択肢を提示
- **誠実**: 不可能なら正直に

### 避ける

- 「お客様のせい」と読める表現
- 法律用語の連発
- 「弊社規定により…」(顧客には無関係)
- 過度に堅い (フランクすぎも問題)

## 怒っている顧客への対応

エモーショナルな案件は**特殊**:
- まず**共感**を示す
- 主張を**繰り返して**確認 ("〇〇 ということでしたか")
- 解決策を提示
- 失敗を**認める**
- 補償 (返金、クーポン)

エージェントの**メンタル**もケア:
- 暴言客の検知 + マネージャ介入
- 休憩・ローテーション

## クライシス対応

→ [[../40-Bridge/Site-Reliability-Engineering]] (将来)

大規模障害時:
- ステータスページ (statuspage.io)
- 一斉メール / SMS
- SNS 投稿
- AI Bot が一次案内
- 復旧後のポストモーテム公開

## オムニチャネル

複数チャネルの**履歴統合**:
- メール → チャットへ移行しても文脈継続
- 複数デバイスからの問合せを一つのスレッドに
- アプリ内とブラウザの統合

Intercom / Zendesk 等のプラットフォームが実現。

## セルフサービスへの誘導

```
[ チャット入力 ]
   ↓
[ AI: "ログインできない問題ですね。以下が試せます:
       - パスワードリセット
       - メールアドレス確認
   役に立ちましたか? [はい][いいえ・人間に聞きたい]" ]
```

「**まず自己解決**」を促す UX。人間への誘導は**簡単**でなくてはダメ(隠す = 不信)。

## アクセシビリティ

→ [[Accessibility]]

- スクリーンリーダー対応のチャット
- 字幕付き電話 (TTY 対応)
- キーボードのみで操作
- 多言語対応 (機械翻訳でも提供)

## 国際化

→ [[../40-Bridge/Internationalization]]

グローバルサービス:
- 言語別チーム
- タイムゾーンを跨ぐ24h対応
- 文化的な丁寧さ (日本の敬語 vs カジュアル英語)

## 顧客フィードバックループ

サポート → プロダクト改善:

```
1. チケットのタグ集計 (頻出問題)
2. プロダクトチームに共有
3. 機能改善 / ドキュメント更新
4. 「変更しました」を該当顧客に通知
```

「**ヘビーユーザーの 1 件の声**」より「**サポート 100 件の傾向**」が改善優先度の根拠。

→ [[../40-Bridge/Discovery-and-Validation]]

## アンチパターン

- 人間到達が**極めて困難** (隠す)
- AI Bot が**ループ**(同じ質問繰り返し)
- 文脈引き継ぎ**なし**(エスカレーション毎に再説明)
- 解決後の**フォローアップなし**
- マクロ機械応答で**人間味ゼロ**
- セルフサービス**なし** → 24h サポートが必須化
- フィードバックがプロダクトに**届かない**

## チェックリスト

- [ ] **セルフサービス**(ヘルプ + AI)が充実しているか
- [ ] 人間到達が**簡単** (3 クリック以内)か
- [ ] チケットに**文脈が引き継がれる**か
- [ ] エージェント側に**AI 補助**があるか
- [ ] CSAT / NPS を**測定**しているか
- [ ] サポート文言が**共感的・明確**か
- [ ] フィードバックが**プロダクトに反映**されているか
- [ ] 多言語・アクセシビリティ対応か
